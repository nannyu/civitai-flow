## 本次发现并修复

- **收藏数据丢失与账户混用**：写入成功后的旧快照可能覆盖刚收藏的作品；未上传的本地文件夹可能在换账户后被上传到新账户。现在将操作保留到读回确认，文件夹绑定账户，断开密钥会使在途响应失效，磁盘写入成功后才更新内存。
- **同步期间编辑丢失**：收藏面板打开后，网站新同步的其他归属可能被旧选择覆盖。保存现在只合并面板中的实际增删；同步读取期间继续收藏也不会丢掉云端新成员。
- **删除收藏夹与元数据缺失**：网站删除有本机待同步修改的文件夹时，原流程会持续失败；图片 API 缺少部分元数据时可能误判为取消收藏。现在保留独立的成员 ID，删除冲突转为本机恢复收藏夹，由用户明确重新同步。
- **比赛集合误当收藏夹**：比赛模式的集合写入属于投稿，可能涉及报名费。普通收藏同步已排除 Contest 集合，既不展示为普通收藏夹，也不写入。
- **分级不一致**：模型预览固定选择普通内容，下载预览绕过 R+ 遮罩，旧字段与新字段冲突时可能过度放行。现在统一按更严格的已知等级判定，下载保留等级，并可从旧记录元数据恢复。
- **播放生命周期**：多张卡片可同时播放，旧播放器异步回调可能污染新状态，关闭弹层可能恢复用户手动暂停的视频。现在限制单卡播放、隔离过期回调，并区分页面离开与弹层遮挡；网站媒体在隐藏、后台和退出时暂停。
- **刷新与分页**：重新保存同一 Key 后未必刷新、空等级仍请求接口、过滤后的空分页可能停在同一作品。现在使用凭据版本触发刷新，空等级不请求，自动继续读取有限数量的被过滤页面，仍保留手动加载入口。
- **下载预览**：不可播放格式可能只显示黑屏，大图片在重绘时反复完整解码。现在给出播放失败说明，并在选中文件时生成有尺寸上限的预览。
- **相册假成功**：PhotoKit 可能接受仅有头部的截断图片，且旧 EXIF 时间会让新保存内容出现在很早的日期。现在实际解码验证图片、等待事务确认、保留临时文件至复制完成，并使用导入时间。失败不会显示成功浮窗。
