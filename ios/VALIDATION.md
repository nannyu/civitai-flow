## 安装 Xcode 后的验收顺序

1. 按 README 命令运行无签名模拟器构建，再打开工程运行。
2. 验证发现页滚动、筛选切换、创作者搜索、下拉刷新与断网重试。
3. 打开视频，上下滑动、切换 Tab、打开提示词、进入后台；确认仅当前视频播放。
4. 收藏作品、退出并重启；确认恢复、搜索和取消收藏正常。
5. 复制公开提示词，验证无元数据作品提示准确；分享链接和评论链接正确。
6. 在真机分别验证图片/视频保存，以及相册授权允许、拒绝后的提示。
7. 检查深色模式、动态字体、VoiceOver 和 iPad 横竖屏。
